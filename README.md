
# Vol Events 🍊

Vol Events is a simple campus events chatbot designed for the University of Tennessee, Knoxville.

The chatbot helps students, prospective students, faculty, staff and alumni discover campus activities and events.

## Features

- Friendly conversational interface
- Six event discovery categories
- Natural-language questions
- Date-based event filtering
- Context-aware event recommendations
- Displays one or two recommendations at a time
- Option to request additional events
- Fallback responses for unsupported questions
- Link to the official UTK events calendar

## Technologies

- Python
- Streamlit
- JSON

## Installation

1. Clone or download this repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

4. Open the local URL provided by Streamlit.

## Event Information

The initial version uses fictional demonstration events
stored in events.json.

For verified and current event information, users are
directed to the official UTK events calendar:

https://calendar.utk.edu/

## Limitations

- Does not register users for events.
- Does not purchase tickets.
- Does not guarantee event availability.
- Does not access private event information.
- Does not provide unrelated university support.
- Demonstration events are not official UTK announcements.

## Project Purpose

This project was developed as a university assignment
to demonstrate chatbot design, conversation flow,
intent recognition and basic user interaction.
